PART 5A work session, start to finish

Start

Type /start-session W2-3.

  • Pulls the latest code.
  • Reads this week's tasks and recent logs.
  • Tells you what your partner changed.
  • States the goal and waits for your go-ahead.

During

  • One agent, one branch, one plan item.
  • Stay in your track's folders.
  • Message your partner before touching a shared file.

End

Say "we're finishing up" or type /end-session.

  • Runs the checks and reports honestly.
  • Pushes the branch and opens the pull request.
  • Summarises the session and writes the log.

A log is a short file named by date, person and topic, for example 2026-10-06-sara-signin.md. It records the plan item, what changed, check results, anything your partner needs to know, the next step, and any plan change to raise on Sunday. Because each session has its own file, two people never edit the same log.

PART 6Rules that stop collisions

Nobody pushes to the main branch.Every change is a pull request the other person approves, with checks passing.
Branches live two days at most.Small pull requests your partner can read in ten minutes.
The plan changes on Sunday only.Mid-week proposals go in your log.
Database changes are new files.Never edit a merged migration; tell your partner when one merges.
Generated files are regenerated.On a conflict, take the main version and rebuild, never merge by hand.
New libraries get their own pull request.Merged the same day, with a line in the decision log.
Never two agents on one branch.Parallel agents each get a separate working copy.
The AI does not rewrite the rules.Specification, plan and CLAUDE.md change only when you both agree.

PART 7The Sunday review

Thirty to forty-five minutes, together.

  1. Demonstrate the week's deliverable on staging.
  2. Decide whether it passed.
  3. Read the week's logs, especially the plan changes people raised.
  4. Edit the plan and note why.
  5. Write next week's task list with an owner on every item.
  6. Write a short review log and merge everything in one pull request.
